# Калькулятор зарплаты бригады

Android-приложение, внутри которого открывается HTML-калькулятор оплаты бригады по часам (`app/src/main/assets/index.html`).

## Как получить APK

При каждом пуше в ветку `main` GitHub Actions собирает APK и выкладывает его в раздел **Releases** (файл `calculator-zarplaty.apk`). Скачайте его на телефон и установите (может понадобиться разрешить установку из неизвестных источников).

Сборку можно запустить и вручную: **Actions → Сборка APK → Run workflow**.

## Как поменять калькулятор

Отредактируйте `app/src/main/assets/index.html` и закоммитьте в `main`, и через пару минут появится новая сборка.

APK подписан ключом `app/zarplata.keystore`. Он одинаковый для всех сборок, поэтому новые версии ставятся поверх старых без удаления.
